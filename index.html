⚡ 실시간 시세 연동

처음 설정하는 방법 (약 10~15분, 한 번만)
  1. 한국투자증권 Open API 신청 — 한국투자증권 계좌로 KIS Developers(apiportal.koreainvestment.com)에서 Open API를 신청하고 앱 키·앱 시크릿을 발급받아요.
  2. Cloudflare 무료 가입 후 Workers & Pages → Create → Worker를 만들고, 코드 편집 화면에 함께 드린 kis-relay-worker.js 내용을 전부 붙여넣고 Deploy해요.
  3. Worker의 Settings → Variables and Secrets에 아래 값을 Secret으로 추가해요.
    KIS_APP_KEY · KIS_APP_SECRET · KIS_ACCOUNT(계좌번호 앞 8자리) · RELAY_KEY(직접 정한 긴 비밀번호)
    계좌상품코드가 01이 아니면 KIS_PRODUCT, 모의투자면 KIS_MODE=mock 도 추가해요.
  4. (권장) Storage & Databases → KV에서 네임스페이스를 만들고, Worker의 Settings → Bindings에 이름 TOKEN_KV로 연결해요. 접근 토큰을 하루 동안 재사용해 증권사 쪽 재발급 제한에 걸리지 않게 해 줘요.
  5. Worker 주소(https://….workers.dev)와 RELAY_KEY를 위 칸에 입력하고 저장하면 연결 테스트, 종목 목록 받기, 보유종목 불러오기가 이어서 진행돼요.
메뉴 이름은 Cloudflare 화면 개편에 따라 조금 다를 수 있어요. 앱 키는 중계 서버에만 저장되고, 이 기기에는 서버 주소와 연결 비밀번호만 저장되며 백업 파일에는 들어가지 않아요.
